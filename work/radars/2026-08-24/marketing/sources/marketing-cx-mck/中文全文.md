# 为 agentic 时代重塑客户体验

2026年7月14日 | 文章

Alex Rodriguez Nicolas Maechler  
Ema Karavdic  Khalid Quidwai

随着 AI agent 承担越来越多瞬时决策，领先企业正在把客户体验从预定义旅程重塑为跨渠道、动态编排。
### （10页）

客户体验（CX）一直是企业最清晰、最持久的竞争优势来源之一。CX 领先者通常会通过深度理解客户需求、重塑端到端旅程、赋能一线团队并严格管理绩效，在增长和总股东回报上优于同行，优势幅度往往高达两倍（图表1）。
如今，曾经让 CX 领导者脱颖而出的能力，正逐渐成为成功的最低门槛。以体验驱动增长不再新鲜；它已经是入场券。AI 为组织提供了打造持久竞争优势的工具。但到目前为止，许多组织的成效仍然有限。原因在于，他们是在碎片化旅程之上叠加 AI，只是在优化步骤而不是决策，并且让交接环节破坏了上下文。
大多数 CX 项目仍然把客户旅程当作设计单元。但客户实际感知到的是持续变化中的决策：展示什么优惠、适用什么政策、触发什么帮助，以及何时由人工介入。如果不重构底层工作流和决策权，AI 只会把现有的一切，包括不一致性，一并放大。
图片：优先重视客户体验的公司在财务表现上优于同行。
即使在 AI 时代，CX 仍然建立在相同的基本原则之上：清晰的客户承诺、以真实客户和一线洞察为基础的以人为本设计，以及与业务结果挂钩的严格衡量。信任也是这项承诺的一部分，因为只有当客户同时感到被保护并受到公平对待时，相关性和便利性才会真正转化为忠诚。
AI 并不会改变这些基本原则；它提高的是组织必须以多么审慎的方式设计和运行客户旅程的门槛，从而让技术放大有效之处，而不是暴露问题之处。这些基本原则会在旅程中的成千上万个细小决策里成功或失败。
Agentic AI 让 CX 发生结构性转变：从设计旅程，转向把动态中的决策作为实时系统来治理。旅程是企业预期客户如何移动的静态表示；动态中的决策则是决定客户实际体验内容的实时选择。
组织不再依赖围绕假设意图构建的预设路径，而是可以部署以目标为导向的 agent，让它们持续解读上下文、消解歧义，并决定何时以及何时不采取行动，且可跨渠道与运营系统执行。人的判断并不会消失；它会前移到上游，负责定义目标、护栏和升级节点，而 agent 负责大规模管理瞬时执行。这是从静态优化向动态编排的转变。
事实上，客户体验正在成为规模化 agentic AI 的试验场。虽然许多企业 AI 项目难以摆脱试点阶段，但 CX 却显得不同：麦肯锡研究显示，在客户面向职能中的 AI 部署，包括个性化、服务运营优化和联络中心自动化，有 41% 已经全面规模化，这使它们比其他业务领域的部署更有可能规模化，概率高出 3.5 倍（图表2）。
在实践中，CX agent 正更快进入生产环境，带来可衡量的影响，并维持采用率。
图片：为 agentic 时代重塑客户体验
原因是结构性的。在过去十年中，以 CX 为驱动的组织在数字基础设施、旅程重构和绩效管理方面投入巨大。借此，它们建立了 agentic AI 系统所需的基础：可观测的工作流、明确的决策权、结构化数据，以及既有的人在环模型。因此，CX 在 agentic 转型中扮演双重角色。
对于仍处于 AI 旅程早期的组织，它提供了一个实用的起点，用来展示价值并积累势能。对于更成熟的企业，它提供了一个高影响力的场域，帮助它们从孤立用例转向协调一致、工作流级别的自主性。
## 以 agentic AI 为中心重新思考 CX 旅程
通向 agentic CX 的实际路径，是决策权逐步升级的过程：先改善单一工作流内的决策，再协调某个领域内的决策，最终优化更广泛生态系统中的决策。企业正在沿着三个视野采用 agentic CX，这三个视野由协调范围和决策权的边界定义，也就是 agent 从单一工作流到整个生态系统，能够做出、协调并优化决策的广度。
这里所说的工作流，是指把用户从起始需求带到完成结果的一套可重复流程，例如开户注册或解决账单问题。
在视野1（工作流重构）中，agent 在严格护栏和升级规则下，端到端自主执行单个、定义清晰的工作流；这些能力已经可用，并且正在被各行业组织采用和规模化。定义后两个视野的能力仍在发展中，但有望成为 agentic 驱动客户体验的一部分。
在视野2（领域编排）中，agent 开始协调 CX 某个领域内的多个工作流，优化跨工作流而非孤立任务的决策。而在视野3（生态系统体验引擎）中，agent 将帮助协调跨职能、跨渠道和跨合作伙伴的决策，在共享目标下优化完整的端到端体验。
### 视野1：工作流重构
CX 中的大多数 agentic 生产部署都处于视野1，在这里价值主张最清晰，规模化路径也最短。这些 agentic 方案旨在在明确护栏下端到端运行一个定义明确的工作流；它们最适合支持、服务和销售辅助等可重复、高频的场景。
在这一视野下交付 CX，需要从一开始就具备清晰的流程设计、结构化数据输入、明确的业务规则和护栏、定义好的升级路径，以及紧密的人在环控制。一旦这些基础到位，组织就可以迅速从试点进入生产，并带来可衡量的 CX 和生产力影响。
但工作流重构只是起点。如果企业只自动化某个单一工作流，却没有弄清其下方的决策层，也就是 agent 能决定什么、必须使用什么上下文、何时应升级、以及各项决策如何连接到相邻工作流，那么就有可能把碎片化固化进一个更快的系统里。
视野1 的价值不仅来自更高效地执行工作流，还来自证明在清晰边界内，决策可以被一致、透明且安全地作出。
以下示例展示了企业如何重构工作流，以带来可衡量的 CX 和生产力影响。
* 超个性化支持：Agentic AI 通过将客户知识直接嵌入交互，实现超个性化支持，使 AI agent 能以最合适的行动自主解决查询。一家英国大型能源零售商拥有约 3,500 名呼叫中心员工，为约 600 万客户提供服务，每年处理约 700 万通电话；该公司部署了一个自然语音 agent 来处理首次联系以及高频、低复杂度问题的解决。
不到五个月，该系统就能理解约 75% 的客户需求，并实现 85% 的意图分类准确率。这带来了客户满意度评分（CSAT）6% 的提升，以及超过 $10 million 的年度运行率影响，主要由更高的自动化、更短的处理时长和更广的客户需求覆盖所驱动。
* agent 增强式解决：Agentic AI 也可以作为一线副驾驶，为人工 agent 提供实时指引、上下文洞察和快速信息检索，以处理复杂案例。例如，一家总部位于美国的高端汽车 OEM 就这样做，以提升客户满意度和效率。
这家公司年收入约 $700 million，每年管理超过 50,000 个客户案例，它部署了一个 AI agent，用于综合结构化和非结构化数据，提供个性化问题解决。集成的绩效报告和反馈回路让 AI 与人工工作流都能持续改进，推动首次联系解决率提升 24%，人工 agent 的生产力提升 30%。
这些案例展示了当 agentic 方案锚定于高频场景时，能够快速创造价值的能力。在此基础上，我们映射了 17 个核心 CX 工作流，识别出 6 个最适合在短期内带来影响且实施可行性强的候选项（图表3）。这些工作流之所以突出，是因为它们包含高风险、可重复的决策，同时驱动客户结果和成本：
图片：有六个优先级最高的客户体验工作流，agentic AI 可以在这些工作流中凭借较强的实施可行性带来影响。
* 下一最佳行动：利用跨渠道的实时信号，在恰当的时间选择恰当的干预。
* 账户开户注册和配置：消除一个主要的激活瓶颈，其中结构化步骤可由 agent 为客户执行。
* 购物与方案探索：帮助客户根据其独特情境选择最佳选项，提升转化和交易额。
* 联络中心问题解决：改善成本和信任的最大驱动因素之一，由 agent 处理常见问题，而异常情况则升级给人工员工。
* 个性化案例管理：在解决客户问题时整合完整客户上下文，在每个阶段提供白手套式服务并加快周转，确保案件以更少交接更快推进。
* 机会培育与留存：在关键时刻触发个性化客户触达，以降低流失并推动增长。
这六个工作流构成了 agentic CX 部署的优先用例，也是测试、打磨并在单一工作流内规模化 agentic 能力的高影响路径。一旦建立起来，这些工作流也会为定义视野2 和视野3 的更雄心勃勃转型提供基础。
### 视野2：领域编排
AI agent 可以让单个工作流更高效，但这并不会自动改善客户端到端体验。客户会跨越多个工作流：例如，一个语音 agent 也许解决了眼前问题，但激活仍然卡住，或者流失信号因为下一步决策在别处而被忽视。
视野2，即领域编排，协调某个领域内的多个工作流，使决策保持一致，交接携带上下文，旅程感觉像一条连续的流。
这正是价值开始复利增长的地方。领域编排者不再优化孤立时刻，而是在整个生命周期内协调时机、干预和优先级。
Agentic commerce 是这种转变的早期信号，它把发现、购买和上手接入到一个协调动作中：你的 agent 已经了解你的偏好，缩小选项范围，验证条款，完成购买，并围绕你的日程安排配送或安装，然后把这些上下文带入定制配置和上手接入，因此在交接时不会重置。
早期行为表明这种势头正在形成。例如，麦肯锡最近的一项调查发现，在尝试过 AI 搜索的欧洲消费者中，44% 表示 AI 搜索现在是他们的主要搜索方式，约一半消费者在网上搜索产品时会使用 AI。
企业开始使用 agentic 能力来监测互动的发生过程，然后在各渠道之间协调下一组最佳行动，而不是由不同团队逐一推送孤立优惠。
欧洲一家最大的电信服务提供商，收入约 €40 billion，构建了预测模型，连接跨领域和跨渠道的信号，以决定不仅向客户展示什么优惠，还决定何时、在哪里展示，以及配以哪些支持动作，例如主动服务修复或资格检查。
该系统通过提高参与度和转化带来了 €40 million 的利润影响，说明当决策在整个生命周期中被连接起来，而不是只在单一渠道内优化时，结果会更好。然而，即使是很强的领域编排，如果仍被限制在单一领域内，也可能达不到预期，因为客户仍会跨领域移动，并且会注意到当逻辑、语气或优先级从生命周期的一部分切换到另一部分时的变化。
### 视野3：生态系统体验引擎
随着时间推移，客户体验的真正转型将来自工作流不再只是领域特定能力，而是开始共享上下文、目标和记忆，从而让动态中的决策可以在整个客户生命周期中得到优化。这种整合定义了视野3：agent 开始围绕共享目标，在职能、渠道和合作伙伴之间协调决策的阶段，因此体验被端到端优化，而不是在孤立孤岛中被改善。
要在这一视野下交付 CX，所需的不只是规模化用例。它依赖于一个共享的决策层，其中包含持久的客户身份和统一上下文、平衡客户价值、成本、风险与产能的明确企业目标，以及 agent 在强治理、标准和可审计性下跨系统行动的能力。想象一下：某位客户遇到账单问题和服务中断，而其近期行为显示流失风险正在上升。
agentic 系统不会把可见问题当成全部故事，而是会从客户画像中横向查看，识别其他可能驱动因素，例如设置步骤失败、重复联系历史、待处理订单问题，或表明需求未被满足的使用量下降。
随后，它会端到端解决该情况：恢复服务、修正计费错误、主动向账户返还积分、发送简短跟进以确认关闭，并根据有助于重建信任的方式调整续约路径或方案推荐。复合价值在于每个动作都会强化下一个动作，把原本可能演变为流失的时刻，转化为一种协调、一致且个性化的恢复体验。
今天没有任何组织真正达到这一层级。那些率先行动，并投资于支撑系统级优化所需的基础、运营模式对齐与激励机制的组织，将在视野3 成熟时处于捕获超额收益的有利位置。
## 成功所需：一个六步启动手册
从旅程设计转向决策编排，要求领导者重构的不只是工作流，还包括决策如何被拥有、如何作出、如何衡量以及如何改进。在经历了数年的 gen AI 试验和早期 agentic 部署之后，有六种 CX 特定模式，能够区分出那些正把 agentic AI 转化为可衡量影响的组织。
在这六种模式中，有一个主题尤为突出：成功取决于业务与技术之间真正的伙伴关系，以界定 agent 能做哪些决策、哪些决策必须转交给人工、它们应优化什么目标，以及决策质量应如何随时间改进。领先组织不是把 agentic AI 当作附加在现有流程上的技术层，而是同步重构客户旅程、决策流、运营模式和治理。
* 明确定义 agent 的优化目标以及允许哪些权衡。把业务价值转化为 agent 的清晰目标，例如留存、信任、服务成本和价值实现时间，并明确权衡，这样系统就不会优化错误的东西。这种清晰性也有助于挑选出少数几个自主性最重要的时刻，并尽早衡量影响。
* 围绕决策而非仅围绕步骤重构工作流。不要在碎片化工作流上叠加 agent。要重设计端到端流程和交接，使各步骤之间的决策保持一致，否则 AI 只会更快地放大今天的不一致。
* 让客户上下文流向每一个决策点。尽早投资共享身份和统一客户记录，使上下文能跨渠道流动，客户无需反复重复自己，而 agent 也能基于完整图景而非部分快照行动。
* 与一线团队一起设定决策责任和升级规则。从第一天起就让一线团队参与，定义决策责任、升级阈值以及 agent 与人工之间的交接。这能建立信任，让采用真正落地，并在需要判断和同理心的地方保持人的中心地位。
* 让重要动作可逆，并保持人为控制。设计 agent 时，要让重要动作可以撤销，并在 agent 出错时给人工提供清晰的覆盖点。记录这些覆盖以及其理由，使系统得以改进，而不是重复同样的错误。
* 构建决策级跟踪、测试和控制。规模化所需的不只是治理。应建立监控和评估机制，追踪 agent 做了什么决策以及原因，确认决策质量是否随时间提升，并在强安全和隐私控制的基础上持续调优表现。
随着企业加速其 agentic CX 旅程，也必须以同等严谨的方式对待风险，因为 agent 会跨系统、数据和工作流执行动作，哪怕是很小的错误，例如拉取了错误记录、错误适用了规则，或触发了错误类型的升级，也可能迅速累积为隐私问题或客户承诺失效。因此，CX 是比其他业务职能更高风险的环境，在这里速度和个性化必须与控制相匹配。
为此，agentic CX 系统应在设计和管理上明确人和 agent 的角色及决策边界、定义好的升级路径、持续监控和反馈，以及强身份、访问和审计控制，以确保动作透明且可逆。尽早建立这些防护措施的组织，能够在保护客户信任的同时扩大自主性。（这些想法在麦肯锡的 Rewired AI 转型框架中有更深入的探讨。）
## CX 优势的下一个来源
Agentic AI 不会只是改善客户体验，它还会重新定义客户体验的交付方式。随着决策从静态工作流转向智能编排，战略与执行之间的边界开始模糊。CX 不再只是设计更好的旅程，而是治理持续学习、决策并适应的活系统。
在这种环境下，优势会复利增长：那些把 agentic 能力深度嵌入运营模式的组织，将加快学习周期，以更高精度响应客户，并把人力重新部署到更高阶的判断、创造力和关系建设上。
对领导者来说，问题已不再是 agentic AI 是否会重塑客户体验，而是他们准备在多大程度上主动围绕它重构。若把 agentic AI 当作另一个用例来处理，收益就只会是渐进式的。若围绕受治理的动态决策重构 CX，企业就能从根本上改变服务客户的方式：提供更连贯、更响应、更个性化且更值得信任的体验。
然而，从本质上说，这场转型并不只是关于技术，而是关于企业与客户之间的关系。在客户拥有比以往更多选择、更多发声渠道、也有更高期待的时代，这种关系已经成为差异化的终极来源。Agentic 系统提供了一个罕见机会来强化这种关系：从被动响应式服务和碎片化旅程，走向真正关注个体需求的体验。
抓住这一时刻的组织，不仅会运行得更高效，还会建立更深的信任、更强的忠诚和更持久的连接。从这个意义上说，agentic AI 不只是一个新能力。它更是一次重新想象“真正服务客户”意味着什么的机会。
##### 与我们一起探索职业机会
