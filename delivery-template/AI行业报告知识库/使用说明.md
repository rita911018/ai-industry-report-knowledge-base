# AI 行业报告知识库

1. 第一次使用 AI 问答前，双击 `配置问答模型.command`，选择 DeepSeek 或千问，再按提示粘贴对应 API Key。旧的 `配置DeepSeek.command` 也会自动打开这个新入口。
2. 双击 `启动知识库.command`。终端会保持运行，并自动打开浏览器。
3. 关闭启动终端即可停止本地服务。

不配置 Key 时，文章浏览、筛选、中文全文、英文原文和官方链接仍可正常使用；只有生成式问答不可用。

点击“中文全文”会打开适合直接阅读的 HTML 页面，并可随时返回知识库或跳转官网核对原文。文件夹内的同名 Markdown 译文继续供本地检索和内容审计使用。

默认模型分别为 `deepseek-v4-flash` 和 `qwen-plus`；配置时也可以输入其他可用模型名称。供应商切换发生在本地服务端，网页不会接触 API Key。

API Key 只保存在本文件夹的 `.env.local`，由本机 Node 服务读取，不会发送到浏览器。请勿分享该文件。
