# AI 机会雷达两级目录设计

## 目标

为六个 AI 机会雷达及其导出的独立 HTML 报告增加一致的两级目录，使用户能够在矩阵、完整场景库、优先启动建议和 12/24 个具体场景之间快速定位。

## 适用范围

- 企业法务雷达
- 人力资源雷达
- 零售雷达
- 供应链雷达
- 财务雷达
- 市场营销雷达
- 上述六个领域导出的完整独立 HTML 雷达报告

不改变任何场景数据、评分、优先级、证据或公司案例。

## 信息结构

目录一级固定为：

1. 优先矩阵
2. 完整场景库
3. 优先启动建议

“完整场景库”下提供二级目录，按当前场景编号顺序列出全部 12 或 24 个场景名称。二级场景列表可以整体展开或收起；默认展开，用户收起后在本次页面会话内保持状态。

## 桌面端布局

- 在宽度不小于 `1100px` 时显示左侧粘性目录。
- 目录位于主导航下方，最大高度为可视窗口减去导航和安全边距，超出时在目录内部滚动。
- 主内容向右让出目录空间，保留现有各板块的全宽背景色与视觉层级。
- 目录使用稳定的深绿色表面和浅色文字，跨越深色、浅色板块时均保持可读。
- 当前一级板块和当前场景使用统一强调色、左侧指示线和 `aria-current="location"` 高亮。

## 导航行为

- 点击一级目录，平滑滚动到对应板块。
- 点击二级场景，先重置可能隐藏目标场景的优先级或类别筛选，再展开目标详情、滚动到目标位置，并把键盘焦点移到场景标题按钮。
- 页面滚动时使用 `IntersectionObserver` 同步当前板块和场景高亮；不支持该 API 时，目录跳转仍可使用，只是不自动跟随高亮。
- 浏览器地址栏 hash 与目标板块或场景保持一致，复制链接后可以直接回到相同位置。
- 初始化时若 URL hash 指向场景，则自动定位并展开该场景。

## 移动端

- 在宽度小于 `1100px` 时隐藏固定侧栏，显示“目录”悬浮按钮。
- 点击按钮后从左侧打开目录抽屉，并显示页面遮罩。
- 点击目录链接、遮罩或关闭按钮会关闭抽屉；按 `Esc` 也会关闭。
- 抽屉打开时设置正确的 `aria-expanded`、`aria-controls` 和对话区域标签；关闭后焦点返回“目录”按钮。
- 抽屉打开期间锁定页面背景滚动。

## 导出 HTML

- 导出报告包含相同的一级与二级目录。
- 导出报告的一级锚点对应矩阵、完整场景详情和优先启动建议。
- 点击场景目录项时定位到对应 `export-<scenario-id>`，并确保该场景的 `<details>` 为展开状态。
- 导出文件完全离线可用，不加载外部脚本或样式。
- 打印时隐藏目录、目录按钮和遮罩，不占用纸面。

## 组件边界

共享渲染器 `web/radars/radar.js` 负责：

- 根据当前领域数据生成目录结构；
- 绑定跳转、展开、筛选重置、hash 和高亮行为；
- 在独立 HTML 导出模板中生成对应目录与轻量交互脚本。

共享样式 `web/radars/radar.css` 负责：

- 桌面粘性侧栏与内容留白；
- 当前项、悬停、键盘焦点状态；
- 移动抽屉、遮罩和响应式切换；
- 打印隐藏规则。

各领域数据文件和六个领域 HTML 壳文件不需要单独实现目录逻辑。

## 错误与边界处理

- 场景不存在或 hash 无法解析时不抛出错误，保持页面默认位置。
- 场景被筛选隐藏时，目录跳转必须先恢复全部筛选。
- 场景列表重新按总分排序后，目录仍按稳定编号顺序展示，避免导航位置随临时排序变化。
- 目录过长时只滚动目录本身，不推动页面横向溢出。
- JavaScript 不可用时，页面原有 `noscript` 内容保持可读；不额外显示失效目录。

## 验收标准

- 六个领域雷达均显示相同结构的两级目录。
- 法务与 HR 目录各列出 12 个场景；零售、供应链、财务、市场营销各列出 24 个场景。
- 点击任意场景目录项都会定位并展开正确场景。
- 当前板块与当前场景随滚动正确高亮。
- 小屏幕使用可关闭、可键盘操作的目录抽屉。
- 六个领域导出的完整 HTML 均包含可用目录，打印时目录不可见。
- 现有矩阵、筛选、排序、场景展开、导出和问答功能没有回归。
