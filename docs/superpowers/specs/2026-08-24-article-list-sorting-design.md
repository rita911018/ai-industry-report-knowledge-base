# 知识库文章列表排序设计

## 1. 目标

在知识库首页的文章筛选区增加一个简洁排序入口，让用户可以在不改变当前搜索和筛选条件的情况下，按发布时间或文章评分浏览结果。

## 2. 交互设计

- 在现有筛选区右侧增加一个带可见标签的下拉框“排序”。
- 仅提供两个选项：
  - `最新发布`：按 `publishedAt` 从新到旧排列，作为默认值；
  - `评分最高`：按标准化后的文章评分从高到低排列。
- 切换排序后立即更新当前结果，不刷新页面，并把文章列表滚动到顶部。
- 搜索关键词、来源、时间、类别和优先级筛选保持不变。
- 排序状态写入 URL 查询参数 `sort`，刷新或分享链接后仍能恢复；默认排序不必写入 URL。

## 3. 排序规则

### 最新发布

1. 有效发布日期从新到旧；
2. 同一天的文章按标准化评分从高到低；
3. 日期缺失或无效的文章排在末尾；
4. 最后用文章 ID 稳定排序，避免列表跳动。

### 评分最高

1. 将来源为 10 分制的评分换算为 100 分制，再与现有 100 分制评分比较；
2. 标准化评分从高到低；
3. 同分文章按发布日期从新到旧；
4. 评分缺失或无效的文章排在末尾；
5. 最后用文章 ID 稳定排序。

## 4. 实现边界

- 只修改知识库文章列表，不改变 HR 或法务机会雷达的场景矩阵。
- 不新增升序选项、复杂多字段排序或拖拽排序。
- 排序作用于全部符合条件的文章，而不是只重排当前已加载的前 30 条。
- 继续使用现有“加载更多”机制；切换排序后从排序结果的前 30 条重新展示。

## 5. 错误与兼容处理

- 无日期、无评分或字段格式异常的文章仍可显示，只排在相应排序的末尾。
- URL 中出现未知 `sort` 值时回退为 `date`。
- 下拉框使用原生 `select`，保留键盘操作、焦点样式和移动端可用性。

## 6. 测试与验收

- 单元测试覆盖日期降序、评分标准化、缺失值置后和稳定并列规则。
- 页面契约测试确认排序控件存在且 URL 状态可恢复。
- 浏览器验收确认：切换后顺序正确、筛选条件不丢失、计数不变、无横向溢出。
- 项目全量测试通过后同步到桌面 `AI行业报告` 交付目录，并重新检查本地服务。
