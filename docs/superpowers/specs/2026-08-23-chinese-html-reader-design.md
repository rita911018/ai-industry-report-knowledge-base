# 中文全文 HTML 阅读页设计

日期：2026-08-23  
状态：已通过交互方案确认，等待书面设计复核

## 1. 目标

将 AI 行业报告知识库中 418 篇文章的中文完整译文，从直接打开 Markdown 文件改为打开排版友好的独立 HTML 阅读页。现有 Markdown 文件继续保留并作为 AI 检索、语料分块和归档的权威内容源。

本次改造只改变用户阅读入口，不重新翻译、不删除归档、不改变问答检索逻辑，也不依赖 DeepSeek API。

## 2. 已确认的阅读体验

采用单栏编辑阅读页：正文居中、行宽受控、留白充足，优先保证长文连续阅读和移动端体验。

每篇阅读页包含：

- 中文标题与英文原标题；
- 发布机构、发布日期、文章类别和优先级；
- 中文摘要，以醒目的导读形式展示；
- 完整中文译文及原有标题层级、段落、列表、引用和链接；
- 页首与页尾的“返回知识库”和“查看官网原文”入口；
- 明确说明中文内容为本地归档译文，官网链接是原始来源。

视觉系统沿用知识库现有的暖灰纸张、深墨文字、青绿色主色和赤陶色提示色。页面不加载外部字体、脚本或图片，因此断网时仍可阅读。

## 3. 生成架构

新增一个职责单一的 Markdown-to-HTML 生成模块。它读取归档记录及每篇文章的 `中文全文.md`，经过安全的 Markdown 渲染和统一模板包装，在同一文章目录生成 `中文全文.html`。

生成结果为独立、可直接打开的完整 HTML 文档。每个文件内含必要样式，不依赖知识库服务器的 CSS 或 JavaScript。418 篇增加的少量样式重复换取稳定的离线可读性和可移植性。

生成流程保持确定性：相同 Markdown 和元数据必须产生相同 HTML。HTML 是派生产物，中文 Markdown 仍是唯一需要维护的译文源；未来译文更新后重新运行生成流程即可覆盖对应 HTML。

## 4. 数据与链接

归档加载记录同时提供两个中文路径：

- `localPaths.chinese`：指向 `/archive/.../中文全文.html`，供网页用户阅读；
- `localPaths.chineseMarkdown`：指向 `/archive/.../中文全文.md`，保留内部审计和向后兼容信息。

知识库文章弹窗、AI 回答的来源抽屉和其他“中文全文”入口统一使用 HTML 路径。英文归档和官网原文路径保持不变。

语料构建仍读取 `中文全文.md`，因此 3,587 个现有检索分块及后续重建不会从带导航和样式的 HTML 中取文本。

## 5. 安全与异常处理

Markdown 渲染必须先转义原始 HTML，防止译文中的标签或脚本进入阅读页。允许的结构只由生成器创建，包括标题、段落、列表、引用、代码和链接。

外部链接必须使用安全属性。缺失发布日期、分类或英文标题时隐藏相应字段，不展示空占位。缺失中文 Markdown、标题、官网 URL 或渲染后正文为空时，生成过程必须失败并报告文章 ID，不生成看似成功的空页面。

单篇失败不能被静默忽略；最终部署只允许在 418 篇全部通过验证后进行。

## 6. 交付范围

实施包括：

1. 增加可复用的中文 HTML 生成模块和命令入口；
2. 为工作归档生成 418 个 `中文全文.html`；
3. 更新 corpus 和浏览器文章索引中的中文阅读路径；
4. 更新网页按钮文案及使用说明，明确 Markdown 供检索、HTML 供阅读；
5. 将验证通过的 HTML、索引和网页更新同步到桌面交付目录；
6. 保留所有现有 `中文全文.md`，不改写或删除译文。

行业机会雷达 Tab、企业法务雷达和人力资源雷达不属于本次实现范围；中文阅读改造完成后单独恢复其设计流程。

## 7. 验证标准

自动验证必须证明：

- 正好生成 418 个中文 HTML；
- 每篇 HTML 都有非空中文正文、中文标题、发布机构和官网原文链接；
- HTML 内不包含可执行脚本或未转义的原始 HTML；
- corpus 中 418 条 `localPaths.chinese` 均以 `/中文全文.html` 结尾；
- 418 条 `localPaths.chineseMarkdown` 均指回已存在的 Markdown；
- 本地服务器以 `text/html; charset=utf-8` 返回中文阅读页；
- 文章弹窗与问答来源抽屉均打开 HTML，不再直接打开 Markdown；
- 原有语料文章数、分块数和 AI 检索测试不发生意外变化；
- 桌面最终交付目录与工作归档的 418 篇 HTML 数量一致。

此外进行桌面和移动视口的人工抽查，至少覆盖 BCG、Anthropic、McKinsey、MIT 和 Bain 各一篇，包括一篇包含多级标题、列表、链接或代码块的长文。
