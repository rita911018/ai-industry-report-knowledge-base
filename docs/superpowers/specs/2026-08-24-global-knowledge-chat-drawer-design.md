# 全局知识库问答抽屉设计

## 1. 目标与范围

把知识库首页首屏中占据主要版面的全文问答模块移出内容流，改为右侧悬浮入口。用户点击后打开标准宽度问答抽屉，可针对全部 469 篇归档文章提问；回答必须显示文章来源和链接，点击来源后在左侧直接阅读对应中文全文。

“全局问答”指检索整个归档语料库，而不是只检索当前筛选结果或当前文章。第一版只改知识库首页；HR 和法务雷达页面不复制该控件。

## 2. 页面结构

### 2.1 首页内容流

- 删除首屏现有问答表单、回答区域和最近问题区域。
- 首屏保留知识库价值说明、文章数量、来源范围和进入文章索引的主路径。
- 首屏标题区改为横向主视觉，不再沿用三列布局，也不在标题文本中写死 `<br>`。
- `768px` 及以上宽度时，主标题“问报告，也问证据。”保持一行或最多两条均衡横向行，标题容器至少取得可用内容宽度的 `70%`；窄屏才允许自然换行。
- 标题字号采用容器感知的流式范围，并设置合理的最小汉字行宽，避免在平板宽度被拆成单字或双字列。
- 文章索引继续作为首页主要工作区，并与排序和筛选功能共存。

### 2.2 悬浮入口

- 在桌面页面右下方固定一个高对比度圆形 AI 图标，带文字提示和 `aria-label="问整个知识库"`。
- 图标不遮挡“显示更多”、筛选控件或系统滚动条；页面滚动时保持可见。
- 首次访问显示一次简短提示“向 469 篇全文提问”，关闭后写入本地存储，不重复打扰。

### 2.3 标准研究抽屉

- 点击悬浮入口后，右侧打开约 `520px`、最大不超过视口 `44vw` 的全高抽屉。
- 抽屉包含标题、语料范围、连接状态、连续对话、来源卡片、最近问题和底部输入框。
- 打开抽屉不刷新页面；再次点击悬浮按钮、关闭按钮或按 `Escape` 可关闭。
- 关闭再打开时保留本次会话；刷新页面只恢复最近问题，不恢复完整回答内容。

## 3. 回答与来源

- 继续复用现有 `/api/ask` 接口和经过校验的 `claims`、`citations`、`sources` 数据。
- 每个回答段落就近显示引用编号；回答下方同时列出来源卡片。
- 每张来源卡片显示机构、文章标题、发布日期、引用章节，并提供：
  - `左侧阅读中文全文`；
  - `打开原文归档`；
  - `访问官网原文`。
- 未配置 DeepSeek API 时，抽屉内显示清晰的配置提示，不影响文章筛选和阅读。
- 资料不足时沿用现有边界说明，不生成无来源的事实性结论。

## 4. 左侧来源阅读器

### 4.1 桌面交互

- 点击来源卡片主体或“左侧阅读中文全文”，在视口左侧打开阅读器，右侧对话抽屉保持原状。
- 阅读器占据抽屉之外的可用宽度，使用同源 `iframe` 加载文章的 `localPaths.chinese`。
- 阅读器顶部显示文章信息及三个入口：中文全文、原文归档、官网原文。
- 中文全文为默认视图；原文归档若有本地 HTML 快照则在阅读器加载，否则在新标签页打开现有归档文件；官网原文始终在新标签页打开。
- 若来源包含章节锚点，阅读器加载后尝试定位；无法定位时仍展示文章开头，并在顶部说明引用章节名称。
- 关闭阅读器后恢复原首页，当前问答会话不丢失。

### 4.2 移动端交互

- 小于 `760px` 时，问答抽屉改为全屏面板。
- 点击来源后切换为全屏中文阅读器，并提供“返回回答”按钮；不在窄屏强制左右分栏。
- 官网原文仍在新标签页打开，避免第三方页面嵌入限制。

## 5. 状态、焦点与无障碍

- 页面状态分为：关闭、仅问答、问答加来源阅读器。
- 打开问答时焦点进入标题或输入框；关闭后返回悬浮按钮。
- 打开来源阅读器后焦点进入阅读器标题；关闭后返回触发该来源的卡片。
- 所有图标按钮有可见焦点和中文可访问名称；抽屉使用 `role="dialog"` 与 `aria-modal="false"`，因为左侧页面仍可交互。
- 动画遵循 `prefers-reduced-motion`，减少动态时立即切换状态。

## 6. 技术边界

- 不修改后端检索、回答校验或 DeepSeek 模型选择逻辑。
- 将问答抽屉和来源阅读器作为独立前端模块，首页负责初始化，避免继续扩大现有 `web/app.js`。
- 不在第一版加入多会话管理、回答导出、账户同步或对话跨设备保存。
- 不把第三方官网页面嵌入 `iframe`，以规避跨域和 `X-Frame-Options` 限制。

## 7. 测试与验收

- 静态契约：首屏问答区已移除，悬浮按钮、问答抽屉和来源阅读器容器存在。
- 单元测试：抽屉状态切换、来源链接选择、中文全文默认规则、移动端模式与错误提示。
- 接口集成：回答显示引用和来源；缺少 API Key 时展示配置提示。
- 浏览器验收：桌面 1440px 下问答抽屉约 520px，左侧中文全文可阅读且对话保留；902px 下首页主标题横向展开、不出现单字或双字竖向断行；390px 下无横向溢出并可返回回答。
- 回归验收：文章筛选、排序、文章详情、加载更多和来源外链继续工作。
