# 雷达低刺激鼠尾草绿与深色文字可读性设计

## 目标

统一改善六个 AI 机会雷达及其导出 HTML 的阅读舒适度：移除刺眼的荧光绿，修复深绿色来源卡和公司案例中黑色文字不可见的问题，同时保留 P0、选中状态和证据锚点的识别层级。

## 根因

- 实时雷达主题把 `#c9ff47` 用作大数字、进度条、标题、按钮和边框，亮度与饱和度过高。
- 独立导出 HTML 复制了同一个荧光色，因此导出报告同样刺眼。
- 导出 HTML 的证据卡和公司案例位于深绿色面板，但标题与正文没有显式的深色背景文字颜色，继承了根级黑色。
- 当前测试验证结构和交互，没有覆盖关键颜色变量与深色卡片的显式前景色。

## 选定方向：编辑型鼠尾草绿

采用低饱和的鼠尾草绿作为强调色，不改变深绿、暖白和宋体/衬线标题的整体编辑风格。

- 主强调色：`#a9b77a`，用于深色背景上的小标题、P0 标签、选中态和链接动作。
- 强调深色：`#718052`，用于暖白背景上的大分数与进度条，避免浅绿色在亮背景上发光。
- 深色主文字：`#edf2ee`。
- 深色次文字：`#c1ccc5`。
- 深色卡片背景保持现有墨绿，但证据标题、公司名称、摘要和正文必须显式使用上述浅色文字。
- 风险橙色继续保留，避免风险与普通优先级混淆。

## 覆盖范围

### 实时六领域雷达

修改共享 `web/radars/radar.css`：

- 更换主题强调色变量；
- 降低评分数字、进度条、P0 标签、选中按钮和悬停状态的刺激度；
- 为 `.decision-link strong`、`.company-case-summary`、来源事实与详情正文设置显式的深色背景文字颜色；
- 保持键盘焦点蓝色轮廓，不以低对比度绿色替代可访问焦点。

### 独立导出 HTML

修改 `web/radars/radar.js` 中导出模板的内嵌 CSS：

- 使用与实时页面相同的鼠尾草绿主题变量；
- 暖白背景上的分数和进度条使用强调深色；
- `.evidence`、`.evidence span`、公司案例标题和正文全部显式设为浅色；
- 打印样式继续转换为白底黑字，不受屏幕主题影响。

知识库首页 `web/styles.css` 不在本次范围内。

## 验收

- 六个实时雷达共享同一套低饱和主题。
- 导出 HTML 不再出现荧光绿大数字或进度条。
- 深绿证据卡和公司案例内不存在黑色正文或黑色标题。
- P0、选中态、风险红线和普通信息仍能一眼区分。
- 自动测试锁定新变量及深色卡片显式前景色。
- 浏览器抽查 HR 雷达、一个新增 24 场景雷达及完整导出 HTML，确认无控制台错误和横向溢出。
